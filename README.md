# To Do List App

![Organizer mockup](image.png)

Original project inspiration taken from my personal project, **Organizer** I have yet to decide on a name for the app, but it is a cozy, customizable app for organizing your schedule, money, and tasks. I designed the mockup above in Figma, and this project uses the same lavender radial gradient (`#C69DD2` → `#5554A9`) and glassmorphism style.

Built with HTML, CSS, and JavaScript. Open `index.html` to run.
